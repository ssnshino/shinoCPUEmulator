UI core rules:
- Modern Shell / Retro Machine
- DISPLAY FIRST
- OBSERVER SECOND
- ADAPT, DON'T SHRINK
- BIG TOUCH, SMALL DATA
- MOTION = INFORMATION
- Compact = one major pane
- Medium = primary + one supporting pane
- Expanded = navigation + primary + inspector + optional trace
- future peripherals are normally under DEVICES / Device Dock
- current LED front panel becomes Debug Lab / CPU Inspector
- viewport size, not device detection
- preserve machine state across resize/navigation
- safe-area / reduced-motion / accessible hit targets

- Do not add FDD/UART/Printer functionality merely to populate layout.

Important limits:

- Disk changes persist across in-page RESET/POWER/WBOOT, not browser reload.
- No host disk-image import/export, B: drive, PIP/STAT/ED/ASM/DDT/LOAD or BASIC.
- CPU is instruction-level complete, not pin/cycle-perfect. WAIT/BUSRQ,
  electrical races and multi-byte externally supplied IM0 streams remain out.
- Do not change CPU semantics without a new bounded precision plan and oracle.

Recommended next phase:

Plan browser-reload disk persistence plus explicit image import/export first.
Keep it outside guest CPU/CBIOS semantics where possible. Then consider an
original SHINO file utility or license-audited CP/M utilities; add BASIC only
after storage behavior is stable. One environment, one writer, one purpose
branch. Do not run ChatGPT and Codex as simultaneous writers.

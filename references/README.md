# references

外部資料の索引を置く。

## Put here

- source list
- URLs
- bibliographic notes
- license notes
- small original research summaries

## Do not put here without explicit rights review

- PC-88 / MSX / Spectrum等のROM dump
- proprietary BIOS
- commercial game/application disk image
- copyrighted PDF mirror
- arbitrary binary copied from third-party repositories

必要なら `references/raw/` はlocal-onlyとして使う（.gitignore対象）。

SHINO-80自身のオリジナルfirmware/sourceは将来 `src/` 側で管理する。

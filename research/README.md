# research

CPU / peripheral / emulator architectureの調査記録を置く研究領域。

## Current

- `z80/` — SHINO-80最初のCPU研究

## Research rules

- 一次資料を優先する。
- 事実、既存実装の挙動、SHINO-80の設計判断を混同しない。
- external sourceからのコードcopyはライセンス確認なしに行わない。
- ROM dump / proprietary firmware / unreviewed binary資料をcommitしない。
- テスト結果は再現条件を残す。

研究結果が設計判断へ昇格した場合、`docs/head/` のArchitecture / Specへ反映する。
